# 🧩 Tetris AI – классическая игра в браузере

https://apanevich.github.io/tetris-ai/

Адаптивная реализация Тетриса на чистом HTML, CSS и JavaScript.
Проект создан с помощью локального ИИ-агента qwen3.5:9b.
Игра работает на любых устройствах – от смартфонов до широких мониторов.

## ✨ Особенности

- 🎮 Управление с клавиатуры (стрелки + пробел) или сенсорных кнопок
- 📱 Полностью адаптивный дизайн (mobile first)
- 🧠 Умная система очков: бонусы за несколько линий одновременно
- ⏫ Повышение уровня с ускорением падения фигур
- 🔮 Превью следующей фигуры
- 🎨 Приятная тёмная тема с неоновой подсветкой
- 🚀 Мгновенный сброс фигуры (пробел)

## 🕹️ Управление

| Клавиша        | Действие               |
|----------------|------------------------|
| ← / →          | Движение влево/вправо  |
| ↑              | Поворот фигуры         |
| ↓              | Ускоренное падение     |
| Пробел         | Мгновенный сброс вниз  |
| (кнопки на экране) | Аналогичны для касаний |

## 🛠️ Технологии

- HTML5 + CSS3 (Flexbox, Grid, медиазапросы)
- Vanilla JavaScript (без библиотек)
- Canvas для рендеринга игрового поля
